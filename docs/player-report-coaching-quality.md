# Player report coaching language

Report publication version 7 explains an observed action, its football value,
and a practical next step using the existing web and PDF fields. No layout,
grade calculation, accepted outcome, proof binding, or model-call count changes.

- Distinguish a close-range finish under pressure from a finish after a carry.
- Describe supported shielding, turns and direction changes. A carry does not
  establish a beaten opponent. Link a subsequent completed pass only when it
  belongs to the same identified actor and follows within two seconds.
- Replace broad public grade claims with explanations attached to their existing
  canonical evidence. One completed pass is a useful training starting point;
  limited footage is not proof of poor ability. Numerical grades are retained.
- Group the goals in the opening summary and use a different movement sequence
  for the next paragraph. Align the headline training focus with the first
  development priority.
- Populate the existing outlook circles and stars from the existing overall
  grade, rounded to the nearest whole symbol on the same five-symbol scale as
  the cover. Show the exact /10 grade alongside. The second circle row displays
  the strongest evidence-backed skill and its existing grade. Relabel these
  fields as current-video assessments rather than forecasts of future potential.
  The next training focus replaces an unsupported recruitment-readiness claim.
  Web and PDF consume the same projection; numeric grades do not change.
- Preserve imperative home-drill instructions that mention either foot. Past
  match-foot claims still require their normal evidence. Restore the known Wall
  Ball / First Touch exercise when a saved step contains the old technical
  placeholder, without reconstructing an observed match fact.

Offline validation used the saved Orman700 report and source evidence: six PDF
pages, score 7.4, two goals, thirteen canonical events and unchanged proof objects.
The preview shares the production publication path and requires zero model calls.
Private report data, source video and preview files are not repository fixtures.

Regression coverage includes publication idempotence, unchanged scores, same-actor
sequence linking, unsupported take-on counts, distinct goal situations and the
boundary between exercise advice and observed match claims. The new tests run in
the offline full-report CI workflow.
