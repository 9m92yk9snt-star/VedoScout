# Medium ONNX CPU scaling probe

Three alternating paired rounds processed the same three source-derived crops with one CPU/one intra-op thread versus two CPUs/two intra-op threads. Same medium model, ONNX 1.31.1, inter-op=1, OPENBLAS_NUM_THREADS=1, OpenCV threads=1. All raw output arrays were exactly equal (maximum absolute difference zero). Median time per three frames: 3.081177s versus 1.945189s, 36.9% lower. Sessions loaded outside timing; reference warm-up used the one-CPU session only. The two-CPU run was faster in each pair, but this remains a small shared-host probe, not production vCPU or whole-pipeline equivalence.
